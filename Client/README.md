# KalaNet Client

KalaNet is an online marketplace application with client-server architecture.

## Features
- User authentication with captcha
- Post and view ads
- Shopping cart
- Wallet with token system
- User profile management
- Transaction history

## Build Instructions
1. Install Qt 6.10.2 with MinGW
2. Install CMake 3.16+
3. Run build_all.bat

## Directory Structure
- pages/ - UI page classes
- dialogs/ - Dialog classes
- network/ - Socket communication
- common/ - Shared utilities

## Requirements
- Qt 6.10.2
- C++17 compiler
- CMake 3.16+
